# SQL Scripts

This folder contains SQL scripts for database maintenance, fixes, and utilities.

## RLS (Row Level Security) Fixes
- `COMPLETE_RLS_FIX.sql` - Complete RLS policy fixes
- `fix_rls_policies.sql` - General RLS policy fixes
- `fix_messages_rls.sql` - Messages-specific RLS fixes

## Utilities
- `check_posts.sql` - Utility script to check posts

## Important Notes

⚠️ **Always backup your database before running these scripts.**

These scripts should be run in the Supabase SQL editor or through your database client. Make sure to review each script before executing it.

For migration files, see `nb/supabase/migrations/` directory.
