## 💡 Quick Actions

### Edit Your Profile:
1. Click "Edit Profile" button
2. Fill in basic info, bio, social links
3. Set availability status
4. Add "open to" opportunities

### Add Content:
- Click any **"+ Add"** button in sections
- Fill the modal form
- Save and see it appear instantly

### Build Resume:
1. Go to **Resume** tab
2. Select template and sections
3. Click "Print / Save as PDF"
4. Use browser's save as PDF option

### Adjust Privacy:
1. Go to **Settings** tab
2. Choose profile visibility
3. Set email visibility
4. Toggle activity status
5. Select profile theme

## 🐛 Troubleshooting

### Issue: Can't see new features
**Solution**: Make sure you ran the database migration

### Issue: Profile strength shows 0%
**Solution**: Add some content and refresh the page

### Issue: Can't edit profile
**Solution**: Make sure you're viewing your own profile (not someone else's)

### Issue: Resume export doesn't work
**Solution**: Allow pop-ups in your browser, then click "Print / Save as PDF"
